# Nuestra Semana

Organizador semanal con tres perfiles personalizables y colores diferentes. Los nombres predeterminados son «Persona 1», «Persona 2» y «Persona 3».

El código no contiene datos familiares ni actividades predeterminadas.

## Perfiles

«Personalizar nombres» permite cambiar el nombre de los tres perfiles. Los nombres se guardan únicamente en el navegador.

Los filtros muestran las actividades de todas las personas o de un perfil concreto.

## Actividades

Al crear o editar una actividad puedes:

- Seleccionar una, dos o tres personas mediante casillas.
- Seleccionar uno o varios días de la semana.
- Indicar el horario y, opcionalmente, el lugar.
- Activar «Repetir semanalmente».
- Guardar, editar, eliminar o duplicar actividades.

«Ambos hijos» selecciona los dos primeros perfiles.

Sin repetición, la actividad aparece solo en la semana que estás viendo. Con «Repetir semanalmente», aparece en esa semana y en las siguientes.

Usa «Anterior», «Esta semana» y «Siguiente» para navegar entre semanas.

## Series y cambios individuales

Al editar o eliminar una actividad de una serie puedes elegir:

- Solo esta actividad.
- Toda la serie.

Una modificación individual se separa de la serie original. Las demás repeticiones se conservan. Los cambios individuales ya separados permanecen independientes cuando se modifica o elimina la serie original.

«Duplicar» crea una copia independiente en los días que selecciones.

## Cruces de horarios

La aplicación señala actividades que coinciden en fecha y horario para al menos una persona.

Las actividades consecutivas no se consideran un cruce.

Puedes guardar una actividad con cruce después de ver el aviso. Los cruces se muestran para la semana visible.

## Conservación de datos anteriores

La actualización conserva los nombres y actividades guardados por la versión anterior, incluyendo títulos, horarios, lugares y personas asignadas.

Las actividades del antiguo horario habitual se convierten en repeticiones semanales. Las actividades compartidas anteriores siguen asignadas únicamente a los dos primeros perfiles.

Los datos nuevos se guardan en un formato separado. Las claves originales del almacenamiento anterior no se borran ni se sobrescriben. Antes del primer guardado se conserva un respaldo local del formato previo.

Si los datos no se pueden leer, la aplicación muestra un aviso y bloquea los cambios para evitar sobrescribirlos. Si no puede guardar por falta de espacio o por restricciones del navegador, mantiene los datos anteriores e informa del problema.

## Copia de seguridad sin descargas

«Copia de seguridad» muestra los datos como texto y permite copiarlos para guardarlos en una nota privada.

Ese texto contiene información personal. No lo publiques en GitHub ni lo compartas en chats.

Para restaurarlo, abre «Restaurar una copia», pega el texto y confirma el reemplazo de los datos actuales. Guarda primero una copia de los datos que quieras conservar.

## Privacidad y almacenamiento

Los nombres y actividades se guardan únicamente en el almacenamiento local del navegador.

La aplicación no envía los datos introducidos a servidores ni sincroniza entre dispositivos.

Para conservar tus datos, utiliza el mismo navegador, dispositivo y dirección de la aplicación. Borrar los datos del navegador elimina el almacenamiento local. Cambiar de dominio no traslada los datos automáticamente.

## GitHub Pages

La aplicación utiliza archivos estáticos y rutas relativas. No necesita compilación, cuentas adicionales ni claves.

Para publicarla, configura GitHub Pages desde la rama main y la carpeta / (root).

Prepara las mejoras en una rama de trabajo. Integra todos los archivos relacionados juntos para evitar publicar una actualización incompleta.
