# Nuestra Semana

Organizador semanal con dos perfiles personalizables y la opción «Ambos hijos».

El horario comienza vacío. Los nombres y actividades se guardan únicamente en el almacenamiento local del navegador. Incluye filtros, edición, eliminación y avisos de cruces de horarios. No envía los datos introducidos a servidores ni sincroniza entre dispositivos. Borrar el almacenamiento del navegador elimina los datos locales.

## GitHub Pages

En Settings → Pages selecciona Deploy from a branch, rama main y carpeta / (root). Los archivos estáticos no necesitan compilación ni claves.

## Ejecución local

Con Python 3, desde esta carpeta: `python3 -m http.server 8000`. Abre la dirección local indicada por el servidor. No abras index.html directamente como archivo, ya que utiliza módulos JavaScript.
